# FAII House CRM

I want to build a Premium B2B Sales & CRM Dashboard for my cinema production house called FAII HOUSE.

Please look at the attached React component (faii_outreach_crm.jsx) for the layout ideas, and the attached restaurantsData.json which contains data for nearly 1000 restaurants in Irbid.

Implement the UI using React and Tailwind CSS with a high-end, ultra-modern Cinematic Dark Theme (Rich dark backgrounds, deep charcoal cards, with premium Amber/Gold and Emerald Green accents to match a production house identity).

Data Loading: Embed the dynamic data from the attached JSON file into the system so it populates the table with all rows.

Key Features to include:

Advanced Sidebar Filters: Filter by Segment (Premium, Medium, Testing), Category/Food type, and Communication Status (New, Email Sent, WhatsApp Sent, Meeting Booked).

Smart Action Panel (Right Side): When clicking a restaurant, display all details (Phone, Email, Rating) and Automatically Generate Custom Outreach Messages (Email and WhatsApp) based on the restaurant's segment and type.

Direct WhatsApp Trigger: A button that automatically opens WhatsApp Web with the pre-filled custom message.

Analytics Bar (Top): Display cards showing total restaurants, how many are 'Premium', and current conversion rate metrics.

Please generate a highly scannable, beautifully spaced layout that looks professional and maintains an elite agency branding. Use proper pagination or infinity scroll if needed for performance since we have around 1000 items.
